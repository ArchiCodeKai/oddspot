## 使用方式

1. 四個環境各走一輪下方清單；每項打 ✅ / ❌ / ⚠️（可接受）。
2. ❌ 的項目記下：環境、步驟、預期 vs 實際（截圖更好），回報後逐項開修復任務。
3. 每個環境測兩種登入狀態：訪客 + 已登入（Google 或 LINE 擇一即可）。
4. 手機測試記得直向為主，橫向快速掃一眼不爆版即可。

## 4. 滑卡（探索模式）

- [ ] 首次進入：手勢提示出現一次（左滑略過 / + 只收藏 / 右滑收藏＋行程 / 滾動詳情）；清 localStorage 後重現
