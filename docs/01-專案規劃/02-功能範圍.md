## 地圖功能

- 以使用者位置為中心顯示附近景點。
- Mapbox marker 採主題色，不再用 category 顏色區分。
- 點擊 marker 顯示 SpotPopup。
- 半徑篩選、分類篩選、狀態篩選、難度篩選。
- RouteSheet 可加入最多 5 個點，支援拖曳排序與最佳化。
- 外部導航支援 iOS / Android / desktop，但 iOS app scheme fallback 仍待補。

## 滑卡片功能

- 左滑 / 叉叉：略過。
- 右滑 / 打勾：收藏並加入今日行程。
- 中間 +：只收藏。
- 上下滑 / 滾輪：在卡片內看更多資料，不用「完整詳情」按鈕。
- 手機版首屏不顯示 action buttons，滾到卡片底部才顯示；桌機版保留浮動按鈕。

## 投稿功能

- 必須登入才能投稿。
- 投稿後建立 `status: "pending"`，審核前不出現在公開列表。
- 支援 Google Maps 文字或 URL 解析座標。
- 支援最多 3 張照片，前端壓縮後上傳 Vercel Blob，再把 URL 存入 DB。
- 現階段先不延伸照片功能；下一步重點是防濫用、duplicate check 與審核後續。

## 景點狀態

- `active`：可探索。
- `uncertain`：狀況不明，可能已改變。
- `disappeared`：已確認消失。
- `pending`：使用者投稿待審核，公開 API 不回傳。

## Guest mode 收藏邏輯

1. 未登入使用者收藏 → 存入 localStorage。
2. 使用者登入後 → `useAuthSync` 自動將 localStorage 收藏 sync 到後端。
3. sync 成功後 → 清空 localStorage 收藏。

## 多語言

- 中文（繁體）主要。
- 英文次要（nameEn、descriptionEn 欄位）。
- 使用 next-intl 管理 i18n。
