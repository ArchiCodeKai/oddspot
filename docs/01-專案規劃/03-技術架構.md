## 地圖套件選擇

目前使用 **Mapbox GL JS + react-map-gl**：
- 能控制向量地圖圖層，符合 Acid/Y2K wireframe 地圖方向。
- 可用本機 `src/lib/mapbox-styles/*.json` 管理四套主題。
- 已串 Mapbox Directions / Optimization API，支援 1–5 點路線規劃與最佳化。
- 外部導航仍跳 Google Maps / Apple Maps / web maps，不把導航留在 OddSpot 內。

## 資料庫策略

- **開發環境**: PostgreSQL（透過 `DATABASE_URL`）
- **生產環境**: PostgreSQL（Neon / Vercel 環境變數）
- Prisma 7 需要使用 adapter 模式（`PrismaBetterSqlite3`）

## 圖片策略

- **v1 Seed data**: 本地靜態圖 `/public/spots/`（最簡單）
- **v1 投稿照片**: 前端 Canvas 壓縮後上傳 Vercel Blob public store，DB 只存 URL
- **相容 fallback**: `imageDataUrls` 仍保留驗證與 API 相容，但不作正式儲存方向
- 儲存方式：`images` 欄位存 JSON string 陣列，第一張 = coverImage

## 專案結構

```
src/
  app/              # Next.js App Router pages
    api/            # API routes
    map/            # 地圖頁
    spots/[id]/     # 景點詳情頁
  components/
    map/            # 地圖相關元件
    swipe/          # 滑卡片探索
    ui/             # 通用 UI 元件
  lib/
    constants/      # 分類、狀態、路由、半徑常數
    db.ts           # Prisma singleton
    mapbox/         # Directions/deep-link/style loader
    submit/         # 投稿圖片壓縮與 Google Maps 貼上解析
  store/            # Zustand stores
  types/            # TypeScript 型別定義
```

## 套件使用建議（避免造輪子）

| 功能 | 建議套件 | 狀態 | 說明 |
|------|---------|------|------|
| 滑卡片動效 | `framer-motion` drag | ✅ 已安裝 | 調好 `dragElastic`、`dragTransition` 參數即可，不需換套件 |
| Toast 通知 | `sonner` | ⚠️ 建議引入 | Vercel 出品，Next.js App Router 原生支援，比自製 toast 穩定 |
| 地圖 | `mapbox-gl` + `react-map-gl` | ✅ 已安裝 | 目前正式地圖引擎 |
| 資料快取 | `@tanstack/react-query` | ✅ 已安裝 | 未來 spots fetch 建議遷移至此 |
| 圖片上傳 | `@vercel/blob` | ✅ 已安裝 | 投稿照片已走 Vercel Blob URL |
| 表單（v2 評論） | `react-hook-form` | ⏳ v2 | 效能最佳，與 Zod 搭配驗證 |
| 路線最佳化 | Mapbox Optimization API | ✅ 已實作 | n≤5，使用者可先手動排序再最佳化 |
| 日期格式化（v2） | `date-fns` | ⏳ v2 | 輕量 tree-shakeable，比 dayjs 更現代 |
| 手勢進階控制 | 自製 pointer swipe engine | ✅ 已實作 | 手機 / 平板避免 nested scroll 吃掉 swipe |
| Auth | `next-auth` | ✅ 已安裝 | Step 5 實作 |

> **原則**：已安裝的套件優先用好，不要為了功能重疊再裝新套件。`sonner` 是目前唯一建議盡早引入的。
