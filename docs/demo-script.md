# OddSpot — 5 分鐘 Demo 腳本

用途:面試/展示時照唸。**粗體是要講的話**,`→` 是要做的操作。
事前準備:登入好的帳號、行程清空、瀏覽器開好 production 首頁、admin 分頁先開著備用。
時間抓 5:00,每段結尾有累計時間,超時就砍掉標 ◇ 的句子。

---

## 0:00–0:30 開場(Landing)

→ 開 `oddspot-pi.vercel.app`(用無痕或未登入狀態,才看得到 landing)

**「OddSpot 是一個台灣獵奇景點的探索 App——收的是不會出現在旅遊書上的地方:奇廟、廢墟、巨物、都市傳說。」**

**「開場這顆是 Three.js 點雲地球,桌機和手機是兩套獨立實作。」**◇**「它做完就被我刻意凍結了——單人專案,複雜度要花在產品主線上。」**

→ 點「Start Scanning」進地圖

## 0:30–1:30 地圖模式

→ 拖動地圖、點一個 pin 開 popup

**「地圖是產品本體。查詢有兩種模式:以我為圓心的半徑搜尋,或跟著視窗的 bbox 搜尋,拖地圖會自動切換。」**

→ 右上切一個 theme(例如 blueprint → midnight)

**「四個主題,每個是一份 Mapbox style JSON 加一組 CSS 變數,執行期一起換——所以 marker、popup、整套 UI 跟地圖是一次重繪,不會出現 UI 跟地圖風格對不上的瞬間。」**

→ popup 按收藏,指一下跳出來的 toast

**「每個寫入動作都會告訴你結果去了哪——這個 toast 可以直接點去收藏頁。」**

## 1:30–2:30 滑卡探索

→ 底部 tab 切「探索」

**「不知道要去哪的時候,用滑的:左滑略過、加號只收藏、右滑收藏並加進今日行程。」**

→ 實際滑兩三張(至少一次右滑)

◇**「手勢引擎是自己寫的 pointer 判斷——先分辨你是要垂直捲卡片內容還是水平滑卡,再鎖方向,手機上才不會互相打架。」**

**「行程上限五個點,滿了再右滑,卡片會彈回來並提示,不會默默吃掉。」**

## 2:30–3:30 行程與導航

→ 點頂部「今日行程」開 RouteSheet,拖曳排序一下,按「最佳化」

**「這裡串 Mapbox Directions 做多點路線最佳化——按一下,五個點依實際路網重排,總距離和預估時間即時更新。」**

→ 按 START 開始導航

**「導航交給外部 Google Maps。iOS 上有個細節:沒裝 app 的話 app scheme 會靜默失敗,所以做了 visibility-based 的 fallback chain,自動退到網頁版。」**

## 3:30–4:30 投稿與審核(核心工程含量)

→ 底部 tab「投稿」,貼一段 Google Maps 連結(座標自動解析、地圖預覽出現)

**「投稿支援直接貼 Google Maps 連結,包含手機分享的短網址——短網址會在 server 端沿轉址鏈解析,只信任 Google 網域白名單。照片在前端壓到 600KB 以下才上傳。」**

→ 送出 → 成功頁 → 切到 admin 分頁,核准或拒絕它(拒絕時填個原因)

**「投稿進來是 pending。公開 API 對 pending 和 rejected 回傳跟『不存在』完全一樣的 404,外面列舉不出未審內容。拒絕會附原因,投稿者在自己的狀態頁看得到,但公開 API 永遠拿不到這個欄位——這條有契約測試釘死。」**

◇**「防濫用是兩層:記憶體 burst 限流當減速帶,真正的硬防線是 DB 計數的每日上限——serverless 每個 instance 記憶體獨立,只有 DB 計數是跨 instance 正確的。」**

## 4:30–5:00 收尾

**「整個專案 71 個測試——行為測試驗核心邏輯,像收藏的樂觀更新失敗會自動回滾;契約測試釘安全邊界。單人開發,從設計系統、3D、地圖客製到審核管線都是自己做的。」**

**「技術上我最想強調的是取捨:該深的地方深——地圖客製、安全邊界;該停的地方停——3D 做完就凍結。謝謝。」**

## 常見追問備答

- **為什麼不用 Google Maps SDK?** 要深度換膚與自訂互動,Mapbox style spec 可控性高;成本可預測。
- **為什麼不用 Redis 做限流?** v1 流量下是過度工程;DB 計數已跨 instance 正確,key 格式已預留,之後可無痛換 Upstash。
- **為什麼 node:test 不用 Jest?** 零依賴、啟動快;Node 24 原生跑 TS,行為測試直接 import 純函數模組。
- **guest 收藏怎麼合併?** 登入時把 localStorage 的 ID 陣列 POST 到 sync endpoint 冪等合併,再從 DB hydrate 回 store,取代本地狀態。
