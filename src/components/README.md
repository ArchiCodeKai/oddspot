# components/

依 feature 分子目錄。

| Dir | 用途 |
|---|---|
| `landing/` | 首頁 Globe 場景、Mascot、Acid stickers、HUD |
| `map/` | 地圖頁元件（MapView、SpotMarker、SpotPopup、MapClickEffect） |
| `spots/` | 景點詳情頁元件（SpotDetailShell、SpotActionBar 等） |
| `swipe/` | 滑卡片頁元件（Step 4 開發中） |
| `auth/` | 登入頁元件 |
| `layout/` | 全站 layout 元件（NavBar、ThemeToggle 等） |
| `providers/` | React Provider 包裝（ThemeProvider、QueryProvider 等） |
| `ui/` | 通用 UI 元件（MagneticCursor、Mascot、按鈕等） |

各 feature 的元件設計規格見 `docs/03-元件設計/`。
